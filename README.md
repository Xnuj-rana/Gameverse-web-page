# 🎮 GameVerse – Gaming Website

A colorful and interactive multi-page gaming website built using HTML, CSS, and JavaScript.  
The website displays popular games with images, features, download options, and user interaction.

---

## 📜 Features
- 🎮 9+ game pages (BGMI, Free Fire, GTA 5, Minecraft, COD, Valorant, etc.)
- 🌈 Modern colorful UI with images
- 🔍 Search functionality using JavaScript
- ⭐ Game rating system
- 🔔 Welcome popup message
- 🔗 Navigation between pages
- ⬇ Download button interaction

---

## ⚙️ How to Run
1. Download or clone the project folder  
2. Open the folder  
3. Run `Gameverse.html` in any browser  
4. Explore different games and features
